# Odin Project Admin Dashboard

A CSS dashboard layout exercise based on The Odin Project.

## Goal

Build a responsive admin dashboard using HTML and CSS with a sidebar, header, main content cards, and a right-side panel.

## Structure

- Sidebar navigation
- Top header with search and actions
- Main dashboard area
- Cards and content panels
- Optional recent activity / announcements section


## Notes

This project focuses on CSS layout and grid/flex positioning rather than JavaScript functionality.
